# ronaldoscotti.com

Site pessoal e portfólio de Ronaldo Scotti.

## Tecnologias

- Astro 5.0
- Tailwind CSS 4.0
- TypeScript

## Desenvolvimento

```bash
# Instalar dependências
npm install

# Servidor de desenvolvimento
npm run dev

# Build para produção
npm run build

# Preview do build
npm run preview
```

## Deploy

Site estático gerado na pasta `dist/`.
